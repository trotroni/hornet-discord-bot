# 🎵 Prompt pour projet `musicBot` (YouTube uniquement)

**But du projet :**
Créer un bot Discord appelé `musicBot` qui lit des musiques **uniquement depuis YouTube**, avec gestion de playlists et queues. Toutes les commandes sont prévues pour interagir dans un salon textuel et un salon vocal.

**Source audio unique :** YouTube uniquement
**Langage :** Python (discord.py + yt-dlp + FFmpeg)
**Fonctionnalités principales :** lecture de musique, gestion de queues et playlists, ajout/suppression de musiques.

---

## 💻 Commandes

| Commande                                     | Description                                                                                                                                      |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `/start`                                     | Démarre la music si elle était en pause                                                                                                          |
| `/stop`                                      | Arrête la lecture en cours, vide la queue du salon et déconnecté le bot                                                                          |
| `/pause`                                     | Met en pause la musique                                                                                                                          |
| `/skip`                                      | Passe au morceau suivant dans la queue.                                                                                                          |
| `/play [url]`                                | Joue immédiatement le morceau correspondant au lien YouTube `[url]`.                                                                             |
| `/playadd [url]`                             | Crée une **liste provisoire** si elle n’existe pas et ajoute le lien `[url]` à cette liste.                                                      |
| `/addlist [number] [url]`                    | Ajoute le lien `[url]` à la playlist numéro `[number]`. Si un lien existe déjà à ce numéro, tous les éléments suivants sont décalés vers le bas. |
| `/playlist [number]`                         | Joue la playlist numéro `[number]` dans le salon vocal.                                                                                          |
| `/list {number}`                             | Si `[number]` est fourni, liste tous les liens et titres de la playlist correspondante. Sinon, affiche toutes les playlists existantes.          |
| `/deletelist [number] {number dans la list}` | Supprime la playlist `[number]` entière ou uniquement le morceau `[number dans la list]` si fourni.                                              |

---

## 🗂️ Gestion interne

* Chaque salon vocal peut avoir sa **queue individuelle**.
* Les playlists sont numérotées et persistantes en mémoire dans un fichier JSON.
* Chaque lien YouTube est transformé en flux audio via `yt-dlp` + `FFmpeg`.
* La commande `/playadd` est destinée à créer une **liste temporaire**, qui peut ensuite être transformée en playlist permanente via `/addlist`.
* La recherche par **titre ou URL YouTube** est supportée.

---

## 🔊 Exigences techniques

* Installer `discord.py` et `yt-dlp` via pip.
* FFmpeg doit être installé et dans le PATH.
* Chaque commande doit gérer les cas d’erreurs (salon vocal manquant, lien invalide, playlist inexistante, etc.).
* La lecture se fait **dans le salon vocal de l’utilisateur**.

---

### 💡 Notes supplémentaires

* Pas de Spotify ou Deezer, uniquement YouTube.
* Les URLs doivent être valides et accessibles.
* Les playlists sont **modifiables dynamiquement**, avec ajout et suppression de liens.
* Les commandes doivent renvoyer des **messages clairs** dans le salon textuel pour indiquer l’état de la queue ou des playlists.
* Les messages envoyé sont des embeds sous cette forme :
# /stat
@bot.tree.command(name="stat", description="Stat sur le bot")
async def info(interaction: discord.Interaction):
    command_log(interaction.command.name, interaction.user.id, interaction.user.name)
    await interaction.response.defer(ephemeral=CONFIG["EPHEMERAL_GLOBAL"])

    guild = interaction.guild
    if guild is None:
        users_list_chunks = ["Commande utilisable uniquement dans un serveur"]
    else:
        members = sorted([member.mention for member in guild.members])
        users_list_chunks = []
        chunk = ""
        for m in members:
            if len(chunk) + len(m) + 2 > 1000:
                users_list_chunks.append(chunk.rstrip(", "))
                chunk = ""
            chunk += m + ", "
        if chunk:
            users_list_chunks.append(chunk.rstrip(", "))

    servers_list = ", ".join(f"`{g.name}`" for g in bot.guilds)
    servers_count = len(bot.guilds)

    version = CONFIG["VERSION"]
    delta = date_now() - START_TIME
    days = delta.days
    hours, remainder = divmod(delta.seconds, 3600)
    minutes, _ = divmod(remainder, 60)
    uptime_str = f"{days}j {hours}h {minutes}m"

    embed = discord.Embed(title=t("core.stat.title"), color=discord.Color.pink())
    for chunk in users_list_chunks:
        embed.add_field(name=t("core.stat.members", member_count=interaction.guild.member_count),
                        value=chunk, inline=False)
    embed.add_field(name=t("core.stat.servers", servers_count=servers_count), value=servers_list, inline=False)
    embed.add_field(name=t("core.stat.version"), value=f"`{version}`", inline=True)
    embed.add_field(name=t("core.stat.uptime"), value=f"`{uptime_str}`", inline=True)

    cpu_temp_str = get_cpu_temperature()
    try:
        cpu_temp = float(cpu_temp_str.replace("'C", ""))
        status = cpu_temp_verification(cpu_temp)
        value = f"`{cpu_temp:.1f}°C` — `{status}`"
    except (ValueError, TypeError):
        value = "`N/A` — ⚪ Inconnu"

    embed.add_field(
        name=t("core.stat.cpu_temp"),
        value=value,
        inline=True
    )

    embed.timestamp = date_now()

    await send_with_warning(interaction, embeds=[embed])
